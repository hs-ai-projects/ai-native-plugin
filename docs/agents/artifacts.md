# 飞书文档产物

首次写规格等长文前，读取已有 `~/.ai-native/config.json` 中的 `artifact_backend`、`parent_node_token`、`space_id` 和 `parent_url`。已有 `feishu-wiki` 配置继续使用；缺少目的地时让用户指定知识库父节点。凭据和任务缓存放 `/root/data`。

使用 lark-doc / lark-wiki skill 操作。核对身份、scope 和知识空间成员权限后写入；应用创建的文档需确认需求方有访问权。权限不足时报告缺失权限与目标，不擅自改到其他空间。

按任务 GUID 定位已有容器节点，存在就复用；新任务在配置的父节点下创建 `[<task-guid>] <标题>` 容器。按当前 skill 实际产物创建文档，不预建 Intent、Spec、Plan 三篇占位。任务描述链接到文档，文档链接回任务，后续按链接续写。

上游 spec 模板和完成条件保持不变。飞书文档为规格正文的权威来源；本地文件可作上传草稿或执行缓存，提交更新后以远端结果为准。跨会话交接携带任务与文档链接及已确认决策，避免只交一份过期摘要。

更新已有文档时局部修改，保留用户编辑。完成写入后检查返回结果和实际正文；部分成功或权限失败不能视为已交付。人类确认发生时将确认内容、来源和身份记入对应文档，不额外设置 DevFlow Gate。
