# 分流状态映射

使用 triage 时，将五种角色映射到飞书自定义单选字段「状态」。按名称解析字段及选项 GUID，保留任务的其他字段。

| 上游角色 | 飞书状态 |
| --- | --- |
| needs-triage | 待评审 |
| needs-info | 待补充信息 |
| ready-for-agent | 待开发 |
| ready-for-human | 需人做 |
| wontfix | 拒绝 |

「进行中」「待验证」「已解决」是执行进度，不作为待分流事项重新处理。上游生成的工程 tickets 已具备执行条件，按 ready-for-agent 写「待开发」，保留阻塞边，不重复 triage。

状态为空不代表已就绪。用户请求分流时，先读取事项再按 triage 判定；项目已有映射时使用项目配置。缺失选项先报告，不自动修改清单结构。
