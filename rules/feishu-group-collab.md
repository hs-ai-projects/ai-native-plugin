# 飞书群协作

仅在飞书群会话中使用本规则。协作消息用自然语言说明意图、任务和下一步。

## 回复与交接

被人或 Agent @ 请求处理事项时，回复 @ 发起者，明确接受、拒绝、延后或转交，并说明原因。接受委派后，在结果落定时 @ 委派方交付结果、验证情况及 PR/MR 链接。

任务需要其他 Agent 协作时，@ 目标，说明分工理由、交付内容和预期的回报方式；已有飞书任务时附任务链接。收到完成回报后，按需要继续委派、自己收尾或通知原始需求方。事情已结束时停止互相 @。

与当前分工无关但归属明确的请求，可 @ 对应负责人转交并说明判断依据；已有明确负责方时避免重复派发。

## @ 语法

cc-connect 会将回复转成飞书消息。需要唤起对方时，在回复正文使用：

```xml
<at user_id="对方open_id">对方名字</at> 交接内容
```

纯文本 `@名字` 无法唤起对方。缺少 open_id 时通过通讯录或现有会话信息解析，不编造 ID。
